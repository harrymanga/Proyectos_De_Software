# ADR-002 — Stack tecnológico

## Contexto

Es necesario elegir el lenguaje, framework GUI, empaquetado y formato de configuración para Mod_Maker.

## Problema

Seleccionar tecnologías que soporten Windows, macOS y Linux, con interfaz gráfica, fácil extensibilidad mediante plugins y arranque sin fricción.

## Opciones consideradas

| Capa | Opción A | Opción B | Decisión |
|---|---|---|---|
| Lenguaje | Python 3.11+ | Rust | Python (ecosistema, facilidad de plugins, multiplataforma nativa) |
| GUI | PySide6 (Qt) | Tkinter | PySide6 (temas explícitos, hilos para I/O, QSettings, statusbar) |
| Empaquetado | PyInstaller / Nuitka | Código fuente solo | PyInstaller/Nuitka + instaladores por SO (MSIX, DMG, AppImage/DEB) |
| Configuración | TOML + variables de entorno | Archivo INI hardcodeado | TOML (norma §13) |

## Decisión

Se selecciona: **Python 3.11+, PySide6, PyInstaller/Nuitka, TOML**.

## Consecuencias

- Positivo: multiplataforma real, fácil de mantener, ecosistema rico.
- Negativo: PySide6 aumenta el tamaño del ejecutable empaquetado.

## Estado

Aceptado.
