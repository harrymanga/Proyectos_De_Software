# ADR-004 — Seguridad de extracción y reconstrucción

## Contexto

La extracción y reconstrucción de mods manipula archivos del sistema de archivos del usuario. Es necesario prevenir ataques de path traversal y ejecución de código arbitrario.

## Problema

Cómo garantizar que la extracción de un mod no escriba fuera de la carpeta de destino y que no se ejecuten scripts peligrosos.

## Opciones consideradas

1. Validar rutas con `pathlib.resolve()` y bloquear traversal — seleccionado.
2. Extraer sin validación (confiar en el usuario) — rechazado (riesgo de seguridad, norma §25).
3. Ejecutar scripts de mods dentro de un sandbox — rechazado para el MVP (los mods no se ejecutan, solo se gestionan como datos).

## Decisión

Se implementa validación de seguridad en `src/core/security.py`:
- Prevención de path traversal al extraer miembros de archivos ZIP.
- Bloqueo de extensiones potencialmente peligrosas (`.exe`, `.dll`, `.sh`, `.bat`, etc.).
- Validación de nombres de mod (sin caracteres prohibidos).
- Los mods nunca se ejecutan; solo se empaquetan, extraen y gestionan como archivos de datos.

## Consecuencias

- Positivo: protección contra path traversal y archivos maliciosos.
- Negativo: algunos archivos legítimos con extensiones bloqueadas se omiten con advertencia.

## Estado

Aceptado.
