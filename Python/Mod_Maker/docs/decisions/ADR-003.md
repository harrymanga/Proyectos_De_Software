# ADR-003 — Formato de paquete de mod de Factorio

## Contexto

Factorio distribuye mods como archivos `.zip` que contienen al menos un archivo `info.json` con metadatos, y opcionalmente `data.lua`, `data-updates.lua`, `data-final-fixes.lua`, gráficos y sonidos.

## Problema

Definir la estructura de metadatos y el formato de empaquetado para mods de Factorio en Mod_Maker.

## Opciones consideradas

1. Usar directamente el formato nativo de Factorio (`.zip` con `info.json`) — seleccionado.
2. Crear un formato propietario intermedio — rechazado (añade complejidad innecesaria, norma §3).

## Decisión

Se adopta el formato nativo de Factorio: archivo `.zip` con `info.json` obligatorio. Los metadatos incluyen nombre, versión, autor, descripción, `factorio_version` y dependencias.

## Consecuencias

- Positivo: compatibilidad directa con Factorio; los mods creados se pueden instalar sin conversión.
- Negativo: depende de que Factorio no cambie su formato de `info.json`.

## Estado

Aceptado.
