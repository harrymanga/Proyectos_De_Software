# Plantillas de mods para Factorio

Este directorio contiene plantillas y esquemas para crear mods de Factorio
con Mod_Maker.

## Estructura

- `info_json_example.json`: Ejemplo de archivo `info.json` válido
- `schemas/`: Esquemas JSON para validación de metadatos

## Uso

La plantilla se aplica automáticamente al crear un nuevo mod desde la GUI
o desde la línea de comandos.
