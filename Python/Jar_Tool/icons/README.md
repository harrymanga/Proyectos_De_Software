# Iconos para JarTool

## Ubicación
Todos los iconos de la aplicación deben guardarse en esta carpeta `icons/`.

## Icono principal
- **Nombre**: `jartool.ico`
- **Formato**: ICO (formato de icono de Windows)
- **Tamaños recomendados**: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256 píxeles

## Cómo crear el icono
1. Diseña tu icono en cualquier editor de imágenes (Photoshop, GIMP, etc.)
2. Exporta en formato PNG con transparencia
3. Convierte a formato ICO usando herramientas online como:
   - https://convertico.com/
   - https://www.icoconverter.com/
   - O usa herramientas como GIMP que pueden exportar directamente a ICO

## Sugerencias de diseño
- Usa colores que representen archivos JAR (naranja, café)
- Incluye elementos como: un frasco, una caja de herramientas, o archivos comprimidos
- Mantén el diseño simple y reconocible en tamaños pequeños

## Iconos adicionales (opcionales)
Puedes agregar otros iconos para:
- `jartool.png` - para versiones Linux/Mac
- `jartool.icns` - para macOS
- `toolbar_*.png` - para botones de la interfaz
