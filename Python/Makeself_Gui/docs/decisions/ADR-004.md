# ADR-004 — Plantillas + append + empaquetado

## Contexto
El usuario necesita crear `.sh` desde archivos del juego y añadir archivos a un `.run` existente.

## Problema
Makeself puro exige preparar `archive_dir` a mano; `--append` no estaba expuesto; sin spec de empaquetado ni CI.

## Opciones consideradas
- Solo documentar el flujo manual.
- Generador de esqueletos console/zenity/mojosetup-stub + acción append + spec PyInstaller + CI matriz 3 SO.

## Decisión
Implementar `src/core/templates.py` (stub mojosetup documentado como simplificado, no binario real), `src/core/append.py`, `makeself-gui.spec` y `ci.yml`.

## Consecuencias
El stub mojosetup no es el binario original; sirve para flujo Crear/Inspeccionar sin dependencias externas.

## Estado
Aceptado.
