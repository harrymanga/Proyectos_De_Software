# ADR-001 — PySide6 como stack GUI

## Contexto
Creador multiplataforma Linux/Win/Mac para makeself.

## Problema
Elegir binding GUI mantenible y ligero.

## Opciones consideradas
- PySide6/Qt: nativo, QThread/QSettings/temas incluidos.
- Tauri: ligero pero bridge web + Rust innecesario.
- Electron: binario pesado.

## Decisión
PySide6, congelado para todo lo nuevo del proyecto.

## Consecuencias
Binario ~60MB vía PyInstaller; checklist §58 obligatorio.

## Estado
Aceptado.
