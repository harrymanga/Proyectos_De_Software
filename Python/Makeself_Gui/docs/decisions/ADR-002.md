# ADR-002 — Invocar makeself embebido, no reimplementarlo

## Contexto
Paridad exacta de flags y checksums CRC/MD5/SHA256.

## Problema
Reimplementar el formato `.run` diverge del upstream.

## Opciones consideradas
- Invocar `makeself.sh` vía subprocess en QThread.
- Reimplementar empaquetado en Python.

## Decisión
`src/core/builder.py` construye argv; `src/core/runner.py` ejecuta; la GUI usa `src/gui/workers.py` (QThread).

## Consecuencias
Requiere `bash/tar/compresor` en el SO (ver `system-packages.txt`); en Windows exige Git-Bash/MSYS2.

## Estado
Aceptado.
