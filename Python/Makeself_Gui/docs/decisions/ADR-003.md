# ADR-003 — Estructura src/ + i18n por archivos

## Contexto
Cumplir §§54/57: estructura por funciones e idiomas con carga dinámica.

## Problema
El bootstrap usaba `app/ backends/ ui/` planos y textos incrustados.

## Opciones consideradas
- Mantener plano: fricción futura.
- Migrar a `src/gui|core|lang|themes`: coste único bajo.

## Decisión
Migrar. `src/gui/` único con widgets. Idiomas en `src/lang/lang_xx.json`, español por defecto con fallback. Test `test_i18n.py` verifica paridad.

## Consecuencias
Imports con `src/` en `sys.path`; agregar idioma = añadir un JSON.

## Estado
Aceptado.
